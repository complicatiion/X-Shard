### 2. Local and Offline Operation of the Software
* **Fully Local Processing:** Once downloaded, this software operates locally on your device. All data generation, file processing, and configuration storage occur on your local machine and on storage locations or devices you select yourself (see Section 3).
* **No Data Collection or Telemetry:** The application does **not** collect, store, process, or transmit any personally identifiable information (PII), usage metrics, crash reports, or telemetry data to the developer or any third party.
* **No Third-Party Tracking or CDNs:** No external Content Delivery Networks (CDNs), remote web fonts, advertising SDKs, analytics frameworks, or tracking tools are embedded or utilized within the software.

---

### 3. Optional Network Features (Network Shares, Console Transfer, Online Lookups)
* **Network Shares:** If you select source or output folders on a network share (for example a NAS via SMB), the software reads and writes files there through the file access of your operating system, using the network credentials managed by Windows. The software stores the paths you selected locally in its settings.
* **Console Transfer (FTP):** This feature is **disabled by default**. If you enable it, the software connects only to the console address you enter and transfers the game files you select to that device. The FTP protocol used by console dashboards is unencrypted; use it only in networks you trust. The console address, user name and the FTP password are stored locally; the password is encrypted for your Windows user account (Windows DPAPI).
* **Update Check and Emulator Downloads (GitHub):** Only after your consent, the software asks GitHub (GitHub, Inc., USA) for the latest X-Shard release, and – if you request it – downloads emulators from the official GitHub release pages of their projects. GitHub receives your IP address and the program version (User-Agent) and processes them under its own privacy statement. The automatic update check is disabled by default and can be switched off at any time; consent can be withdrawn by switching the feature off.
* **Online Title Lookups:** Optional lookups of title information by the included backend take place only after you switch off Offline mode and confirm the request. The respective online service then processes the technical connection data under its own responsibility.
* **No Transmission to the Developer:** None of these features transmits data to the developer or to any third party chosen by the developer. The connections are made only to the shares, devices or services you select.

If your personal data is processed (e.g., when you contact the developer via email), you have the following rights under the GDPR:
* **Right of Access (Art. 15 GDPR):** Request information about your processed personal data.
* **Right to Rectification (Art. 16 GDPR):** Request correction of inaccurate data.
* **Right to Erasure (Art. 17 GDPR):** Request deletion of your data, unless legal obligations require retention.
* **Right to Restriction of Processing (Art. 18 GDPR):** Request restricted processing of your data.
