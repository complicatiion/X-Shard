# Integrated legal documents — v0.1.9

Seven documents are included in the first-start reader, its acceptance hash and the sequential Inno Setup pages: LICENSE_DECLARATION.md, EULA.md, PRIVACY_POLICY.md, LEGAL_NOTICE.md, COPYRIGHT.md, THIRD_PARTY_LICENSES.md and GPL-3.0.md.

The project declaration and EULA reflect the publisher's GPLv3 license choice. Root LICENSE.md retains canonical GNU GPLv3. docs/nfo/X-SHARD-LICENSE.md provides a standalone project Markdown license. GPL-3.0.md reflows the complete GPL for the reader. THIRD_PARTY_LICENSES.md explains component scope, offline defaults and local storage.

Original component licenses remain in the root `licenses` folder; release output contains licenses and corresponding GUI/XGD source archives in sources. The GUI EULA does not replace a backend license or restrict GPL rights. LEGAL_DOCUMENT_MANIFEST.json records current document hashes.
