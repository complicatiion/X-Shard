# Changelog

## 0.1.9

### New

- Appearance: new default theme **Dark** — neutral dark gray with the Windows 11 Mica backdrop (solid #202020 on Windows 10 or when transparency is off).
- New **Xbox** theme: the previous dark green theme; it always uses the Xbox green accent (accent picker disabled while active).
- Default accent color is **Green**; new optional accent **Windows** follows the Windows accent color and updates live when it changes.
- Default UI language remains English (also after Reset).
- Light theme uses the all-green X-Shard logo in the header and About dialog (the white "X" was invisible on light backgrounds).

### Changed and fixed

- Defaults: Dark theme + Green accent + English. Existing 0.1.8 settings keep their theme and accent ("Dark" now shows the gray Mica look; choose "Xbox" for the former green look). Settings from 0.1.9 pre-release builds that were auto-switched to Xbox/Windows are reset once to Dark/Green.
- Job details arrow expands the details inline again (regression in 0.1.8: a height check almost always fell back to the details window). The drawer takes 220–420 px from the queue (queue keeps at least 120 px); on small displays the workspace scrolls instead of opening the window. The selected job and the drawer are scrolled into view.
- Output target dropdown (Custom folder, Xemu, Xenia, RetroBat, Batocera) and the sort dropdown no longer show leading icons.
- Queue header: search box, status filter and sort dropdown are exactly 42 px high, matching the icon buttons; the after-queue dropdown uses the same height and no longer shows the power icon.
- Settings › Settings and queue location: Open log folder and Open reports folder share the full card width in two equal columns.
- "Settings saved" notification removed.
- First-start "X-Shard information" dialog (legal reader) follows the active theme: background and headings no longer use the fixed Xbox green.
- Publisher shown in Windows "Programs and Features" / "Installed apps" is now **sksdesign** (installer `AppPublisher`, `VersionInfoCompany`; `Company` in the EXE file properties). Author/copyright remain Sven Klocke.
- Installer: own wizard artwork — large X-Shard image with logo and green gradient on the welcome/finish pages, small logo tile on the other pages, in five DPI sizes (`installer/wizard`, regenerated by `make-wizard-images.py`).
- README with new preview screenshot (`preview/preview.jpg`) and favicon (`preview/favicon.png`).

## 0.1.8

### New

- Title information read offline from images and folders: Title ID (with publisher code), name, region, version, disc and title icon for Xbox Classic (`default.xbe`, incl. the DXT/XPR title image); Title ID, Media ID, region, version and disc for Xbox 360 (`default.xex`), name and icon from GoD/STFS headers. Shown in the queue row and in a new Title tab.
- Target preview tab (destination, expected structure, estimated size, free space incl. network shares) and a free-space warning before the queue starts.
- Run reports as TXT or self-contained HTML (status, duration, sizes, space saved); export from the queue footer or save automatically to the reports folder.
- Taskbar progress, taskbar flash and a Windows toast notification when the queue finishes (Windows SDK projection, toggle in Settings).
- Optional hibernate or shutdown after the queue with a 60-second countdown, Cancel and Now; session-only.
- Explorer context menu: Extract/Convert with X-Shard for .iso/.xiso, Create XISO with X-Shard for folders (installer task for all users, Settings toggle for the current user); single instance with a local named pipe forwards new files to the running window.
- `xshard-cli.exe`: extract, create, list, rewrite, convert and info for scripts, same planner/backends/settings, offline by default (`--online`), `--report`, exit codes; self-contained trimmed single file.
- Queue search (Ctrl+F), status filter and sorting; filter for image contents.
- Dark, light or Windows theme and six accent colors; check marks, selections, sliders and progress bars follow the accent.
- Emulator integration: Xemu/Xenia executables and game libraries, RetroBat and Batocera targets (`roms\xbox`, `roms\xbox360`); single-file results are placed directly in library folders; Start in emulator.
- Local crash logs (newest ten) with a notice on the next start and Open log folder in Settings.
- Polish and Danish UI (flat flags, Nordic cross for Danish).

### Changed and fixed

- Inline job details no longer squeeze the window: the drawer is a real layout row, the workspace always gets the full viewport width, the queue keeps a minimum height, and on small displays the arrow opens the details card instead.
- Taskbar icon: new ICO with 15 sizes (16–256, incl. 20/30/36/40/60/72/80/96 for 125–200 % scaling), small sizes as uncompressed bitmaps; shared AppUserModelID for the process and the installer shortcuts.
- Console selection now comes before the operation.
- "Xbox Classic" naming throughout (console, profiles, queue, README); new short description: "X-Shard is an Xbox 360 and Xbox Classic ISO tool for the community".
- "local-first" wording removed from README and descriptions (behavior unchanged: offline by default, Yes/No before external services).
- Projects: `XShard.Core` (shared, net10.0), `XShard` GUI (net10.0-windows10.0.19041.0, runs on Windows 10 1809+), `XShard.Cli`; JSON persistence uses source-generated metadata.
- Repository: `LICENSE.md` in the root with an identical copy `licenses/X-Shard-LICENSE.md`; legal reader documents back in `docs/legal` (byte-identical to 0.1.6, no new acceptance needed when updating from 0.1.6); `docs/FEATURES.md`.
- Release script publishes both EXEs into one folder; installer sets the AppUserModelID and offers the context-menu task.

## 0.1.7

- Consent: X-Shard contacts no external service on its own. Opening a website/repository link (About and links inside the legal reader) and disabling XGDTool offline mode each require an explicit Yes/No confirmation card. No, Escape and a background click decline.
- Online consent is per session: every start of X-Shard begins in offline mode. Queued jobs saved with offline mode disabled ask again on Start; No runs them offline. Source-content inspection always lists offline.
- Auto UI scaling now adapts to the logical window size (Windows DPI already applied): 100% from 1280×820, reduced in 5% steps down to 70% so compact 11–14" displays show all cards without vertical scrolling.
- Settings in two columns (one column on narrow windows) with grouped cards; flat 2D vector flags beside each language name (English, German, Spanish, French built in; optional `Flag` attribute for additional XML languages).
- Vertically centered text in the UI-scaling percentage pill and the settings/queue location pill (pill text is centered globally).
- New gear icon for the Settings button; new Job details icon for the footer button and the Job details title.
- Footer button reads only "Job details".
- About shows the author "Sven Klocke" above sksdesign | complicatiion.
- Device profiles read "Xbox · Xemu Emulator" and "Xbox 360 · Xenia Emulator".
- Skip $SystemUpdate is on by default for Xbox extraction, including a one-time default migration for settings written by earlier versions.

### Build and project structure

- A Visual Studio **Release** build now runs the release script automatically (MSBuild target `XShardPackageRelease`): self-contained single-file publish, portable ZIP, Inno Setup installer and SHA-256 files. Opt-out via `XShardPackageOnBuild=false`, portable only via `XShardBuildInstaller=false`; recursion guard `XShardReleaseScript`.
- Release script: strict mode, MSBuild-formatted errors (`XSB001`), early Inno Setup 6.3+ detection (PATH, registry, Program Files, per-user), cleanup of VS MSBuild environment variables, separate publish intermediate/output folders, temporary source stage removed, old GUI source archives pruned, optional `-RunVerification`, extended output checks.
- Installer: `{autopf}` install folder, AppVerName/VersionInfo/UninstallDisplayName, compile-time check for Inno Setup 6.3+.
- Repository layout: `LICENSE` in the root with an identical copy `licenses/X-Shard-LICENSE.txt` (kept in sync by the script); third-party licenses moved to `licenses/`; source accompaniment moved to `sources/`; `docs/` contains only CHANGELOG.md, DEPENDENCIES.md and FEATURES.txt; all further documents in `docs/nfo/` (legal reader documents in `docs/nfo/legal`).
- EULA path reference updated to `docs/nfo/legal`; the legal reader asks for acceptance once more after updating.
